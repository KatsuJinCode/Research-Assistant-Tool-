-----------------------------------------------

    ├── (:Project {id: 'default', name: 'Default Project'})
    ├── (:Claim {id: 'c1', project_id: 'default', ...})
    ├── (:Document {id: 'd1', project_id: 'default', ...})
    └── All queries automatically filter by project_id

PROJECT ISOLATION:
-----------------
  Method: Logical isolation via project_id property
  Filtering: Automatic in all graph queries
  Performance: Indexed queries (project_id_index)
  Data Safety: Complete isolation between projects

SESSION MANAGEMENT:
------------------
  Storage: Active project in database (is_active flag)
  Syncing: WebSocket events for real-time updates
  Persistence: Survives page reloads
  Switching: Triggers graph reload
